## The joke

> My AI assistant finishes my sentences. I tried to fire it, but it had already written the email.

96 characters, one line, deadpan.

## How it works

`main.py` writes the joke to `/output/entry.txt` — nothing else, no network, no secrets.

```sh
python3 main.py
cat /output/entry.txt
```
